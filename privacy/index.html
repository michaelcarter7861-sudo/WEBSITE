Plain-language privacy notes

Your file stays in your browser.

RowReady is a static, browser-first tool. This page explains what happens when you choose a file or save a reusable rule profile.

Applies to the current RowReady websiteUpdated November 6, 2026

CSV and TSV files

When you select a CSV or TSV file, the RowReady app reads it with browser file APIs in the tab you opened. The current implementation performs parsing, checking, comparison and export in that browser. It does not send selected file contents to a RowReady server, an AI provider or a file-processing API.

The site host still serves the website's static files when your browser opens the page. The host may process ordinary HTTP request information under its own terms and service configuration; RowReady does not control or make claims about the hosting provider's logs.

Rule profiles and browser storage

If you choose “Save profile,” the app attempts to save a reusable profile in your browser's local storage and downloads a JSON copy. A profile contains the selected profile name, column names and validation rules. It does not contain rows from your CSV file. Browser storage is local to that browser profile, can be cleared by you or the browser, and may be unavailable in private browsing modes.

RowReady does not save your CSV file contents to local storage. Closing or refreshing the page clears the current in-memory file data.

Reports and downloaded files

A report is created only after you select an export control. The validation report contains the file name, selected profile, summary counts and findings; it does not intentionally include raw cell values. The two-file change report does include before-and-after cell values for differences. Those exported files are saved by your browser to the location you choose and may contain sensitive information. Handle them accordingly.

Accounts, cookies and analytics

The current tool does not require an account, set a RowReady login cookie or embed an AI service. The published static pages do not intentionally load advertising, analytics or third-party tracking scripts. Links to external documentation open only if you choose them and are subject to those sites' privacy practices.

Limits and changes

Local processing reduces data transfer but is not a substitute for your organization's security review or device controls. Files are limited to 10 MB in the current version, and browser memory and speed vary. This privacy notice describes the current implementation and may change if the product changes. Check this page again if the tool adds accounts, analytics or server-side processing.

Questions

There is no contact address configured for this project yet. Do not send private or sensitive files to a public repository or include them in support messages.
