# BusinessCalc Hub

A static-first collection of free business and ecommerce calculators. Calculations run in the visitor's browser; no account or file upload is required.

## Stack
- HTML, CSS and vanilla JavaScript
- No build step or package dependencies
- Cloudflare Pages static hosting

## Cloudflare Pages deployment
1. In Cloudflare, open **Workers & Pages → Create application → Pages → Connect to Git**.
2. Select this repository and the `main` branch.
3. Leave the build command empty.
4. Set the build output directory to `/`.
5. Deploy. Pushes to `main` trigger deployments after Git integration is enabled.

## Initial tools
- Profit Margin Calculator
- Markup Calculator
- Break-even Calculator
- Selling Price Calculator
- Ecommerce Profit Calculator

## Important
Calculators provide estimates based on user-entered assumptions. They are educational tools, not accounting, tax, investment or legal advice. Verify inputs and applicable local rules.

## Roadmap
Expand only after reviewing real search demand and user feedback. Potential additions include inventory, shipping, marketplace fee and cash-flow tools.
