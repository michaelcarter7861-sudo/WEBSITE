Good questions

Before you upload anywhere.

Understand what the checker can—and cannot—tell you.

Are my CSV files uploaded?

No. RowReady reads a file you select with browser APIs. The app does not send its contents to a RowReady server or an AI service. Your selected rule profile is saved locally only if you choose to save it.

Can this guarantee my import will work?

No. Each destination has account settings, custom fields and rules that a standalone browser tool cannot inspect. RowReady checks selected common patterns, not the full destination system. Always review the platform's own import preview and keep a source copy.

Does the Shopify profile validate every Shopify rule?

No. It highlights a specific documented variant-column dependency and basic file issues. It cannot see your store, locations, custom data, old templates or the exact import choices you make. See the Shopify CSV safety guide.

Can I save rules for the next file?

Yes. Export a rule profile as JSON and import it later, or save it in this browser. The profile contains your column rules, not your CSV records.

What happens when a file is too large?

The current version accepts files up to 10 MB. Performance varies by browser and device, so large files may take longer. Split a larger export into smaller files; do not upload sensitive data to an unfamiliar service just to work around a local limit.

Does it cost anything?

RowReady is free to use in this version. There is no account, paid AI, or upload service. This does not guarantee that the service will remain available forever.
